# 연속 검수 개선 계획

기준: main d092bb370525ea465d449547949c02386a94b239. 착수 시 변경 없음.

1. 페이지·항목·셀을 하나의 선택 세대로 관리한다. 읽는 동안 이전 대상의 쓰기를 막는다. 브라우저 초안은 작업 공간/항목/셀과 기준 스냅샷에 연결한다.
2. 원본 옆 검토 패널에서 사람이 수정안/이유를 작성하고 기존 pending 제안으로 등록한다. 한 제안 ID의 변경 전후와 승인 버튼을 함께 둔다. 채팅은 변환 영역 아래에 배치한다.
3. 검색/의심 후보를 유지되는 작업 목록으로 만들고 셀 검색, 추가 결과, 이전/다음, 재개를 연결한다. 검수 집계는 저장 이력을 수정하지 않는 파생 표시로 계산한다.

문서/스키마/참조/위치와 기존 명시 승인·stale·재제안·되돌림·내보내기 복구 계약을 유지한다. 구조 편집/변환/이미지 AI는 제외한다.

완료: 별도 시험 Asset에서 직접 텍스트/셀 제안→대조→승인→다음, 목록 유지, 대상별 초안 왕복/재시작/기준 변경, 지연 응답, 표 전체 유지 이후 셀 보류, stale/undo/export 복구를 검증한다. 1366×768과 넓은 화면 및 키보드를 확인하고 필수 unittest 전체와 위험별 회귀를 실행한다. 실제 사용자 데이터는 해시로 보존 여부를 확인한다.
