# 대화 중심 검수 화면

- 범위: 기본 2열(대화 + 원본 근거), 메시지에 연결한 단일 제안 카드, 전체 대상/예외와 승인 범위, 상태별 실행 행동, 좁은 화면 전환, 보조 탐색/직접 수정/이력 경로.
- 재사용: 기존 Conversation, BatchReview, Store, 원본 좌표·이미지, 모델 목록과 승인·복구 검사. 프레임워크와 별도 진단 모델을 추가하지 않는다.
- 제외: 실제 모델 호출, 사용자 문서 교정, 기존 서버 재시작, 원본 변경, 커밋·푸시·배포.
- 완료: 시작·질문·범위 조정·승인·다음 문제와 중단/재개/실패/복원, 직접 수정 복귀, 오래된/중복 승인 방어를 격리 Asset에서 검증한다. 1366/1920/좁은 화면의 전후 캡처와 전체 unittest 결과, 원본 파일 해시 비교를 남긴다.
- 변경 전: 대화/제안의 분리된 스크롤, 3열 상시 편집기, 중복 설정/탐색 메뉴가 주 흐름을 분산한다. 작업 트리는 `54a03ad`에서 깨끗하며 기존 52741 서버를 보존한다.
